# Стамбуляк-8 · DATA/LAB

Авторський навчальний вебсайт для Стамбуляк Діани Святославівни.
Тема: робота з даними, формулами та візуалізацією в Excel.

## Вміст
- `index.html` — головна сторінка (рівень 1)
- `topics/` — три тематичні розділи (рівень 2)
- `lessons/` — по два уроки для кожного розділу, шість уроків загалом (рівень 3)
- `assets/` — стилі, скрипт та фавіконка.

## Як відкрити
1. Розпакуйте ZIP.
2. Двічі натисніть `index.html` — сайт працюватиме локально навіть без інтернету (використовуються резервні системні шрифти).
3. Клацайте по розділах, уроках та інтерактивних прикладах.

## Як опублікувати і отримати URL
1. Перейдіть на https://app.netlify.com/drop
2. Перетягніть цілу папку `stambulyak-excel-lab` (всередині має бути `index.html`).
3. Netlify створить публічне посилання. Відкрийте його в приватному/інкогніто вікні й перевірте сторінки.
4. Надішліть це URL викладачеві.

## Що треба персоналізувати
Група: 8. Назва сайту: «Стамбуляк-8». Авторка: Стамбуляк Діана Святославівна.

## Авторські рішення
Дизайн і тексти створені спеціально для цієї роботи, без покупного шаблону. Дані в демонстраційних прикладах навчальні.
