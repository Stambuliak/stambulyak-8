СТАМБУЛЯК-8 / DATA LAB — ВИПРАВЛЕНА ВЕРСІЯ ДЛЯ GITHUB PAGES

Усі HTML, CSS, JavaScript і favicon розташовані в одному рівні.
Вже опублікована версія була завантажена на GitHub без папок assets, lessons, topics — і стилі втратили шлях.
Ця версія адаптована до такого розташування.

Як оновити:
1. Розпакуйте цей ZIP.
2. Відкрийте GitHub -> Stambuliak/stambulyak-8 -> Add file -> Upload files.
3. Перетягніть УСІ файли з розпакованої папки (не сам ZIP).
4. Натисніть Commit changes; погодьтеся із заміною файлів.
5. Після завершення публікації відкрийте https://stambuliak.github.io/stambulyak-8/ і натисніть Ctrl+F5.

index.html, style.css і site.js мають бути в корені репозиторію.
